# WA STUDIO — تصميم وتطوير المواقع (Next.js)

إعادة بناء لـ بهوية WA STUDIO (أخضر غامق + ذهبي + كريمي)، مع RTL عربي كامل.

الصفحة الرئيسية مطابقة لتخطيط الموقع المرجعي بالقياس: أُخذت أبعاد ومواضع كل قسم من المرجع عند عرض 1440px وضُبطت الأقسام عليها (ارتفاع الصفحة 4508px مقابل 4507px في المرجع)، مع استبدال ألوان وخطوط المرجع بالهوية.

## التشغيل

```bash
npm install
cp .env.example .env.local
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run start
npm run lint
npm run format
```

## متغيرات البيئة

انظر `.env.example`:

| المتغير | الوصف |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | رابط الموقع للـ SEO |
| `NEXT_PUBLIC_WHATSAPP_NUMBER` | رقم واتساب دولي بدون `+` |
| `NEXT_PUBLIC_GTM_ID` | معرّف GTM (فارغ = معطّل) |
| `DB_HOST` / `DB_PORT` / `DB_NAME` / `DB_USER` / `DB_PASSWORD` | اتصال MySQL للوحة التحكم |
| `ADMIN_PASSWORD` | كلمة مرور الدخول إلى `/admin` (8 أحرف على الأقل) |

بدون `DB_*` يعمل الموقع العام من ملفات المحتوى، واللوحة لا تحفظ. عند أول اتصال ناجح تُنشأ الجداول ويُنقل إليها المحتوى الحالي مرة واحدة.

## لوحة التحكم

1. اضبط متغيرات MySQL و`ADMIN_PASSWORD` في `.env.local` (أو لوحة الاستضافة).
2. شغّل الموقع وافتح `/admin/login`.
3. أدر المقالات والخدمات والمشاريع من هناك؛ المنشور يظهر في الموقع والسايت ماب فوراً.
4. من `/admin/channels` عدّل رقم الجوال وحسابات التواصل ومعرّفات منصات الإعلانات.
5. تغيير رابط عنصر منشور أو حذفه يُنشئ تحويلاً دائماً `308` حتى لا تنكسر الروابط المفهرسة.

## تعديل المحتوى

- المقالات والخدمات والمشاريع: من `/admin` عند اتصال MySQL، أو من ملفات `content/` كمصدر أولي قبل أول نقل.
- النصوص الثابتة (الهيرو، التذييل، عنّي…): `content/ar.ts`

## تعديل الهوية البصرية

1. الألوان والـ radius والظلال: `app/globals.css` (`:root` + `@theme`). المشروع على Tailwind v4 الذي يقرأ التوكنات من CSS، لذلك `tailwind.config.ts` نسخة TypeScript مرجعية فقط (`brandTokens`) وليس مصدر التوكنات.
2. الألوان الستة الأساسية فقط مكتوبة كقيم؛ كل الدرجات الأخرى (الخلفية، البطاقات، الحدود، التوهج) مشتقة منها بـ `color-mix`، فتغيير لون أساسي يغيّر الموقع كله.
3. الخط عبر `next/font` في `app/layout.tsx`: **Tajawal** للعربية واللاتينية. أوزانه 200 و300 و400 و500 و700 و800 و900، لذلك `font-medium` يحل محل `font-semibold` (لا يوجد وزن 600).
4. الشعار والصورة الشخصية: `public/brand/` (الصورة `wael.jpg`).
5. في المكوّنات استخدم فقط توكنات مثل `bg-brand-primary` و `text-brand-accent` — لا تكتب ألواناً مباشرة.



## البنية

```
app/                 # صفحات الموقع + /admin + sitemap/robots
components/
  admin/             # واجهة لوحة التحكم
  layout/            # Header, Footer, GTM
  sections/          # أقسام الصفحات
  ui/                # Button, Card, Container...
content/             # نصوص ثابتة + بذرة المحتوى الأولي
lib/                 # SEO, DB, محتوى الموقع، صلاحيات اللوحة
public/brand/        # أصول الهوية
```



## النشر على Vercel

1. ادفع المستودع إلى GitHub.
2. Import المشروع في Vercel.
3. أضف متغيرات البيئة من `.env.example`.
4. Framework Preset: Next.js — البناء تلقائي عبر `next build`.



## قرارات تنفيذية

- مسار المدونة `/blog`. التواصل عبر واتساب مباشرة بدون نموذج.
- صور المشاريع في `public/projects/` أو عبر رفع اللوحة إلى جدول الوسائط.
- مطابقة ألوان المرجع بالهوية: الأسود ← الداكن `#1A1D1F`، الكحلي ← الأخضران، الأزرق الفاتح ← الذهبي بنص داكن.
- الشعار في الهيدر: علامة WA مع الاسم «وائل العلوش» وتحته «تصميم وتطوير المواقع».
- الاسم الشخصي مصدره `siteConfig.name` في `lib/site.ts`. الكتابة اللاتينية في `nameEn` هي Wael Al-Alloush.
